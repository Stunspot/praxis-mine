# Praxis Mine 1.3.0

Compare an outside tool or method with the way you work now, run a useful trial, and decide what to keep or skip.

Start with the [current working guide](source/plugin/skills/praxis-mine/workspace/WORKING-GUIDE.md). Extract the 1.3.0 complete kit and open its Open.cmd on Windows or Open.command on macOS. Existing native work remains in its separate work folder; choose that folder to return. The skill and the direct local app remain complementary ways to do the work.

See the [current release notes](RELEASE-NOTES-v1.3.0.md), [current companion](delivery-v1.3.0/Praxis%20Mine%20T-Free%20v1.3.0%20Extra.md) and [rebuild instructions](REBUILD-CURRENT.md). Earlier version directories and receipts are preserved history and are not the current entrypoint.

The app does not invent research, trial or audience results. Native macOS launch was not exercised in this Windows acceptance pass. Repository source custody, local acceptance and public publication remain separate states.
