# Description

Praxis Mine helps you decide whether an outside tool, skill or method would improve a real task. Compare it with what you do now, identify the mechanism that could help, account for the work and dependencies it would add, and try the smallest useful comparison. Keep the useful part, adapt it, skip it or return when something changes. The local bench makes the comparison and next action concrete; the skill adds investigation and implementation craft in your AI host.

# Usage Notes

Copy the .zip from "Additional Files" to your Codex, Claude Code, or other harness, or add the .zip to a project knowledge base in Chat. Attach or reference the .zip in chat and say, "Install this Augment." The prompt in this post is optional.

Extract the complete kit and open Open.cmd on Windows or Open.command on macOS with Python 3.11 or later. Choose **Assess an idea**, name the tool or method, say what it might improve and describe your existing approach. A plain idea is enough; files are optional when source reading would help.

In **Compare the difference**, choose comparison points that matter for the actual task. In **Try it on real work**, set the same input, improvement criterion and stop condition, then use the candidate in its own environment. Keep what actually happened, with timing only if useful. The app does not run unknown code or invent trial results. Source inspection can be enough for an obvious skip.

In **Decide & act**, explain the decision, remaining uncertainty and concrete next action, then copy the recommendation. **Work folder** chooses a writable saved location and reopens existing native work. Use **Save changes** before closing. Detailed history, evidence and native tools remain available under **More tools**. Back up the complete work folder and copy unsaved comparison notes separately before a recovery reload. A recorded assessment does not install or adopt a candidate.

Windows ordinary-input, material and storage workflows were exercised. Native macOS launch remains untested in this pass.
