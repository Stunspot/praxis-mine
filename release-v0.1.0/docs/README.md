# Praxis Mine

Assess outside skills and practices for bounded adoption, retaining useful mechanisms without wholesale installation or authority drift.

Included skills: praxis-mine.

## Start here

1. Follow the [quick start](QUICK-START.md) for a first useful result.
2. Install the [Codex plugin](INSTALL-CODEX.md) or a [Claude skill ZIP](INSTALL-CLAUDE.md).
3. Check [capabilities](CAPABILITIES.md) and [boundaries](LIMITATIONS.md) before consequential use.
4. Run the [static validation procedure](VALIDATION.md).
5. Use [support and recovery](SUPPORT.md) if packaging, installation, discovery, or behavior differs from expectation.
