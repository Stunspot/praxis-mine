# Praxis Mine 1.1.0 candidate

Baseline: accepted 1.0.1. Treatment: feature update. The new persistent mine room adds a supported visual workflow over the native SQLite source/run/candidate/evaluation ledger, purpose search, chronological browsing, mechanism/applicability/why-cared/project fields, versioned edits with transactional conflict checks, gated evaluations, manifest import and complete exports. Three materially distinct skins and portable private loopback Open wrappers accompany the existing plugin and standalone skill archives.

The importer retains its established per-record commit semantics. Fresh-host discovery, macOS launch and external publication are not established by this local candidate. Arm's Reach remains dormant.
