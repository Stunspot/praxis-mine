# Praxis Mine plugin

Praxis Mine turns outside AI skills, repositories, tools, and workflows into evidence-bounded adoption decisions. It helps you find the useful mechanism without importing the whole package on vibes.

This directory is the installable skills-only plugin. Keep it intact: `.codex-plugin/plugin.json`, `assets/`, and `skills/` are one installation unit.

Start with:

> Assess this outside skill and steal only the good bits.

The complete release kit includes host-specific installation, first-value, workflow, recovery, privacy, validation, and provenance guidance. See the public [Praxis Mine repository](https://github.com/Stunspot/praxis-mine).
