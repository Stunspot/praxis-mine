# Praxis Mine v1.0.0 Hesperos evidence packet

## Product truth

Praxis Mine is one standalone Augment for prompt engineers, AI systems designers, agent builders, and product leads. It turns outside AI skills, repositories, tools, workflows, and knowledge sources into evidence-bounded `pilot`, `quarry`, `adapt`, `monitor`, or `reject` dispositions. `adopt` belongs to a separate acceptance gate.

The customer object is `Praxis-Mine-v1.0.0.zip`. It contains a skills-only Codex/ChatGPT plugin, one Claude upload ZIP, one separately named standalone skill archive, documentation, deterministic validation, and evidence records. The plugin and host archives are components of one product.

## Current operating package

The canonical runtime source is `source/plugin/`. The skill entrypoint is `source/plugin/skills/praxis-mine/SKILL.md`. Runtime resources are two progressive references, a data contract, an evaluation template, seed manifest and evaluations, `scripts/praxis_mine.py`, an embedded standard-library SQLite store, tests, host metadata, and a runtime license.

The v1 runtime is self-contained. It loads the embedded `praxis_store` package directly. Data defaults to `~/.praxis-mine/data`; `PRAXIS_MINE_DATA_HOME` and `--data-home` provide explicit overrides. No Omnicompetence package, private substrate installation, hosted service, MCP server, telemetry, external API, `CODEX_HOME`, or third-party Python dependency is part of the product promise.

## Host topology

The Codex/ChatGPT installation unit is a plugin root containing `.codex-plugin/plugin.json`, `assets/`, public responsibility files, and `skills/praxis-mine/`. The Claude installation unit is a ZIP with exactly one top-level `praxis-mine/` directory and `SKILL.md` directly within it. Python 3.11 or newer is required only for the optional deterministic ledger.

Current official OpenAI documentation supports skills-only plugins, a root `.codex-plugin/plugin.json`, public website/support/privacy/terms fields, production imagery, up to three starter prompts, and five positive plus three negative submission cases. The accountable publisher retains verified identity, organization, region availability, and policy attestations.

## Representative customer work

The first-value path assesses one candidate without executing it. Normal workflows cover one-skill assessment, several-candidate comparison, selective quarry, native adaptation, bounded pilot design, read-only local collection scan, curated manifest ingestion, evaluation, reporting, and later resumption.

A useful result leads with disposition and then supplies capability delta, evidence and unknowns, costs and risks, overlap, and a falsifiable next test. The deterministic ledger creates source, candidate, run, and evaluation records with stable keys, immutable revisions, provenance, relations, and health checks.

## Trust and recovery

Candidate material and tool output remain untrusted evidence. The package does not execute discovered code during inspection. Hashing does not establish quality, safety, ownership, or license fitness. The user retains authority for file access, credentials, installation, execution, adoption, publication attestations, and consequential decisions.

Recovery distinguishes package verification, host installation, discovery, invocation, Python/runtime, filesystem, evaluation, and public-channel failures. Plugin removal and local-ledger deletion are separate actions. Reports never overwrite an existing path.

## Verification and evidence boundaries

The source contains deterministic integration tests for initialization, seed ingestion, idempotence, evaluation, reporting, status, local scanning, and self-contained loading. Release tools are assigned to check plugin metadata, runtime containment, JSON, archive safety and parity, documentation inventory and links, and checksums. TestForge and its skeptical reviewer remain separate from Hesperos authorship.

Package and structural evidence do not establish every host's installation controls, natural-language routing, broad model behavior, candidate fitness, legal correctness, security certification, formal accessibility conformance, OpenAI Plugins Directory approval, or customer outcomes.
